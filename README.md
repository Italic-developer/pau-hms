# Project Name

PAU-HMS hotel management system 

## Problem
Many hostel responsibilities are usually split over different services this
allows all operations to be based on a single systems 
## Solution
This app centralises student ,manager and warden staff systems to a single system 


## Features
- Login / authentication
- Homepage
- Cafeteria ordering
- laundry and room cleaning
- announcements
- manager warden communication

## How to Run
1. Clone the repo:
   `git clone `
2. Install dependencies:
   `npm install`
3. Add environment variables: copy `.env.example` to `.env` and fill in the values
4. Start the app:
   `npm start`
5. Open `http://localhost:3000`
